### AI-Customer-Segmentation-Analysis
An interactive Streamlit dashboard that embeds **AI workflow automation into customer analytics.** The project automates data cleaning, KPI analysis, visualization, narrative generation, and “What‑If” scenario simulation — turning raw e‑commerce data into actionable business insights.

### Features
Automated Data Cleaning: AI‑assisted preprocessing (remove anomalies, fix dates, calculate totals).

KPI Analysis:

 1. Customer Lifetime Value (CLV)
 2. Recency (churn risk detection)
 3. Frequency (loyal vs casual buyers)
 4. Revenue Contribution (Champions vs At‑Risk)
 5. Average Order Value (AOV)

**AI‑Generated Insights:** Each KPI comes with a “why” factor and stakeholder‑ready recommendations.

**What‑If Simulator:** Interactive sliders to model revenue impact of changes in AOV and Frequency.

**Narrative Automation:** AI explains 'why revenue changes' and suggests business actions.
